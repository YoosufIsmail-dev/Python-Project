## 🧩 About the Project

This repository serves as a log of my Python learning journey. Each file represents a small, self-contained script that demonstrates a fundamental programming concept.

It currently includes:

- **Band Name Generator** – A fun script that combines a city name and a pet’s name to create a unique band name.
- **Tip Calculator** – A practical tool that calculates how much each person should pay, including a customizable tip percentage.

These projects are perfect for anyone starting with Python, as they cover input handling, type conversion, arithmetic operations, and basic output formatting.

---

## 📂 Projects Included

| Script | Description | Key Concepts |
|--------|-------------|---------------|
| **Band Name Generator** (`day 1.py`) | Asks for the city where you grew up and the name of a pet, then generates a creative band name. | Variables, `print()`, `input()`, string concatenation |
| **Tip Calculator** (`python day 2.py`) | Takes the total bill amount, desired tip percentage, and number of people, then calculates the amount each person should pay. | `float()`, `int()`, arithmetic operators, `round()`, f-strings |
